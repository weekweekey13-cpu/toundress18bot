Шуточный бот «Раздеть фото» — @toundress18bot

Как пользоваться
1. /start — «Привет! Загрузи фото которое хочешь раздеть»
2. Прислать фото — бот ответит случайным стикером из пака админа.

Админка (только @bonamartin69)
- /admin или кнопка «Админка»
- «Загрузить стикерпак» — пришли любой стикер из пака
- «Показать пак»
- «Статистика»

Это розыгрыш: чужое фото никуда не обрабатывается.
На Render токен только в Environment (BOT_TOKEN), не в коде.
